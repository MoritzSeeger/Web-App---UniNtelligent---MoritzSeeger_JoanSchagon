Beim nächsten Projekt, müssen wir uns nochmal intensiv mit git beschäftigen. Mit Github zu arbeiten war kein Problem, es gab aber teilweise Probleme per git zu pushen, es zu synchronisieren, sodass beide die selbe Version haben. Anfangs hat es noch sehr gut funktioniert, aber als es immer und immer mehr Code und vorallem Codeänderungen gab, kam es zu Mergefehlern, sodass wir gar nichts mehr pushen konnten. Lösung zu dem Problem war dann ein neuer Branch. Aber da wir zum ersten Mal mit git und GitHub gearbeitet haben, ist es normal, dass Fehler auftreten und wir erst draus lernen müssen. Jetzt wissen wir aber worauf wir mehr achten müssen für das nächste Projekt.
